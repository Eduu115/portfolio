What it does

A student picks a challenge and submits a Spring Boot project. API Arena builds it, runs it in its own isolated container, fires real HTTP requests at it, measures how it performs, reviews the code and puts the score on a live leaderboard.

No mocked answers: the API under test is real, and so are the requests.

How a submission is scored

  • 300Functional HTTP tests
  • 300Performance
  • 200REST design
  • 200Code review

Maximum score: 1,000 points.

One service, one job

Java 21 and Spring Boot 3.5 behind an nginx gateway, a React 19 frontend, and Kafka between the parts that should never wait on each other.

A consumer throws

The exception is not swallowed. The event is retried after 1, 2, 4 and 8 seconds and, if it still fails, it lands in that consumer group's dead-letter topic, where it can be inspected. Malformed JSON skips the retries and goes straight there. Consumers are idempotent (natural keys and unique constraints), so a retried event is never counted twice.
